# Autoria e colaboração

Um repositório pertence a uma conta pessoal ou organização, mas pode ter vários colaboradores.

## Créditos do trabalho acadêmico

Registre no README o nome e o link do perfil GitHub de cada integrante, após confirmar os dados e a participação. Os créditos não exigem conceder acesso de edição.

## Contribuições de código

Cada pessoa pode usar sua própria conta e fazer commits ou abrir pull requests. O GitHub associa commits ao perfil pelo e-mail cadastrado na conta. Prefira o e-mail `noreply` disponibilizado pelo GitHub para evitar expor e-mails pessoais.

Se duas pessoas trabalharam no mesmo commit, pode-se usar o trailer `Co-authored-by: Nome <email associado ao GitHub>` na mensagem do commit. Use apenas identidades confirmadas e participação real; não fabrique um histórico anterior.

## Acesso ao repositório

O proprietário pode convidar a segunda pessoa em **Settings → Collaborators**. Isso concede permissão de colaboração; confirme o usuário e o nível de acesso antes de convidar. Nenhum convite é enviado automaticamente por este projeto.

Uma pessoa também pode contribuir por fork e pull request sem acesso direto ao repositório original.
